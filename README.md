# Rimpulse

**Force feedback built from the car's telemetry, with safety you can trust on a direct drive base.** Part of [Riminal](https://discord.gg/XkukAhckz2): sim racing tools so good it's criminal.

This page holds the downloads. Get the newest installer from **[Releases](../../releases/latest)**. Once installed, Rimpulse finds new versions itself.

## What you need

- Windows 10 or 11, 64-bit
- Le Mans Ultimate
- A direct drive wheelbase that supports DirectInput force feedback (tested on Simucube 2 Pro)

## Safety

Rimpulse never sends more force than the cap you set. Force fades out whenever the game pauses, freezes or you leave the car, and it guards against a wheel spinning on its own. **Ctrl+Alt+End** stops it instantly from anywhere.
